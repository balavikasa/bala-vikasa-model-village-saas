# Bala Vikasa Model Village — UI Renewal v2026.27.29

## Purpose

Implements the agreed **new light-theme visual system** in the existing Flask/Jinja, JavaScript and PostgreSQL Model Village SaaS. The provided official Bala Vikasa logo is used directly, including the full wordmark in desktop navigation/login and the symbol for compact application controls and install icons. The original supplied logo file is retained without alteration in `app/static/brand/bala-vikasa-official.png`.

## New JSON endpoints

- `GET /api/v1/monitoring/visit-analytics?month=YYYY-MM&cluster=&da=&village=&committee=` — Admin, PM and PC only. All filters are applied **after** server-authorized village and visit scoping.
- `GET /api/v1/monitoring/recent` — signed-in role-scoped latest village submissions and a pending-village list.

## Key accounting rules

- `villages_done`: distinct village IDs with an active DA-led visit in the specified month.
- `villages_pending`: assigned/in-scope villages with no active visit in that month.
- `people_attended`: sum of active committee attendance rows; not multiplied by member names.
- `new_members`: **one village-wide number** per visit, not committee-wise. Older visit data is handled separately when needed.
- Historical Action Plans and Specials are excluded from new Analytics.
- If a DA records outside their assignments, the assignment owner remains unchanged; the visit is visible in that DA's recent activity.
